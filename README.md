# Python Calculator 

A simple graphical calculator built using Python and Tkinter.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Basic error handling

## Technologies Used
- Python
- Tkinter

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run:

```bash
python calculator.py
```

## What I Learned

This project helped me practise Python functions, conditional statements, event handling, GUI development and exception handling.
